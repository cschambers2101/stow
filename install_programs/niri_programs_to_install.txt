# S6C document and slide fonts. These are for the college's own materials,
# not the desktop shell.
#   Ubuntu  -- the sole S6C brand font (brand.md 3.1). Ships with the Ubuntu
#              desktop already; pinned here so a minimal install still gets it.
#   Carlito -- metric-compatible substitute for Calibri, which the Accessible
#              Slide Standard (brand.md 9A) requires for SEND and dyslexia
#              decks. Calibri itself is not redistributable on Linux. Without
#              Carlito, Calibri falls back to Noto Sans, whose metrics differ,
#              so titles sized to fit a slide reflow and overflow.
#   Arial   -- the brand fallback, provided by ttf-mscorefonts-installer below.
#   Atkinson Hyperlegible Next -- the Braille Institute's legibility face,
#              designed so that easily-confused characters (I l 1, O 0, b d p q)
#              stay distinguishable. Relevant to the SEND and dyslexia intent
#              behind brand.md 9A. NOTE the family name is exactly
#              "Atkinson Hyperlegible Next": ask for plain "Atkinson
#              Hyperlegible" and fontconfig silently hands back Noto Sans.
#              The older v1 packages (fonts-atkinson-hyperlegible*) are a
#              different family and are deliberately not installed.
fonts-ubuntu
fonts-crosextra-carlito
fonts-atkinson-hyperlegible-next
fonts-noto-core
fonts-font-awesome
fonts-cascadia-code
fonts-dejavu-core
ttf-mscorefonts-installer
libqt6svg6
# qt6-svg-plugins is NOT optional, despite the name. libqt6svg6 ships the
#              QtSvg *library* only; the two plugins that let Qt actually
#              decode an SVG live here -- imageformats/libqsvg.so and
#              iconengines/libqsvgicon.so. libqt6gui6 merely RECOMMENDS
#              this package, and section 1 of the installer sets
#              APT::Install-Recommends "false", so on a fresh build it is
#              silently absent and NO Qt6 app can render any SVG. Symptom
#              is easy to misread: quickshell logs "Unsupported image
#              format" for its own logo and every symbolic tray icon
#              renders as a checkerboard, while all of DMS's own icons
#              look fine (they come from a bundled Material Symbols font,
#              not SVG). Found in the test VM 30 Aug 2026.
qt6-svg-plugins
# qt6-gtk-platformtheme is the SECOND casualty of the same no-recommends
#              policy, and the one that actually fixes the broken tray
#              icons. The session sets QT_QPA_PLATFORMTHEME=gtk3, which
#              is how a Qt app learns the GTK icon theme name. Without
#              this plugin Qt loads no platform theme at all, so every
#              QIcon::fromTheme() lookup falls back to bare hicolor and
#              any app-supplied tray icon fails -- regardless of whether
#              it is an SVG or a PNG. That last part is the giveaway:
#              "livepatch" is a PNG and failed too, which is why
#              qt6-svg-plugins alone did NOT fix the bar.
#              Verified in the VM 30 Aug 2026: 3 "Could not load icon"
#              warnings before, 0 after installing this and restarting
#              the shell.
#              NOT added: qt6-qpa-plugins, the third missing recommend.
#              It only ships a TUIO touch plugin and Qt's own VNC
#              platform plugin; xcb, wayland, offscreen and eglfs all
#              come from libqt6gui6 itself.
qt6-gtk-platformtheme
qml6-module-qt5compat-graphicaleffects
qml6-module-qtquick-layouts
qml6-module-qtquick-controls
qml6-module-qtquick-templates
